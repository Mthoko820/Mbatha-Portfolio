# Portfolio Website

## Overview
This portfolio website showcases the skills, projects, and experiences of Mthokozisi Mbatha, focusing on IT, AI/ML, and automation. The site is built using modern web technologies including HTML, CSS, JavaScript, and Vite, ensuring a clean, responsive, and fast user experience.

## Features
- **Responsive Design**: Mobile-first approach with a clean layout.
- **Dark Mode Toggle**: Users can switch between light and dark themes.
- **Animated Hero Section**: Engaging introduction with animated text.
- **Skills Showcase**: Detailed presentation of programming languages, frameworks, and tools.
- **Project Listings**: GitHub-powered or manually curated project showcases.
- **Experience Timeline**: Visual representation of professional experience and achievements.
- **Contact Form**: Easy way for visitors to get in touch.
- **AI/ML Spotlight**: Optional section highlighting smart projects with data visualizations.

## Project Structure
- **src/**: Contains all source files.
  - **css/**: Stylesheets for the project.
    - **components/**: Specific styles for each section.
    - **utilities/**: Reusable styles and animations.
  - **js/**: JavaScript files for functionality.
    - **components/**: Scripts for each section.
    - **utils/**: Utility functions for API calls and animations.
  - **assets/**: Images and resume files.
- **public/**: Static files like favicon.
- **index.html**: Main HTML file.
- **package.json**: Project dependencies and scripts.
- **vite.config.js**: Vite configuration.

## Installation
1. Clone the repository:
   ```
   git clone https://github.com/[your-username]/portfolio-website.git
   ```
2. Navigate to the project directory:
   ```
   cd portfolio-website
   ```
3. Install dependencies:
   ```
   npm install
   ```
4. Start the development server:
   ```
   npm run dev
   ```

## Deployment
The portfolio can be deployed using GitHub Pages or Netlify. Follow the respective documentation for deployment instructions.
